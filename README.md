# Learn `C` college

Just my notes for learning `C` language in college.

## Strucures

`q-x`mean `q` for quadrimester and `x` for the number of the quadri.
Inside of each quadri, there are `module-x` which is the number of the module in that quadri.
And for each module, we have `ws` and `ex` for introduction workshop and exercise respectively.
